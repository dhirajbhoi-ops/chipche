Before You Run It

This local app uses yt-dlp and ffmpeg on your computer. It is for videos you have permission to download.

  1. Install yt-dlp and ffmpeg.
  2. Run start-codex-node.bat or npm start.

The app no longer guesses the length. It uses the real duration from yt-dlp, or a length you type manually.
